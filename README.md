# Churn Intelligence Engine

An explainable customer-churn prediction engine built with **Scikit-learn**, **Random Forest**, **SHAP**, and **Streamlit**. It generates a reproducible synthetic customer dataset, trains a production-style pipeline, identifies the strongest churn drivers for each account, and creates practical risk-mitigation scorecards for account managers.

## Highlights

| Capability | Implementation |
|---|---|
| Reproducible data | 5,000-row synthetic subscription dataset generated with a fixed seed |
| Prediction model | Random Forest classifier with class balancing and one-hot categorical preprocessing |
| Evaluation | Stratified holdout ROC-AUC, classification report, and confusion matrix |
| Explainability | SHAP TreeExplainer for local feature contributions, with a safe fallback |
| Actionability | High / Medium / Low bands plus prioritized retention actions |
| User interface | Streamlit dashboard with portfolio filters, customer explanations, and CSV export |

## Quick start

```bash
git clone <your-repository-url>
cd churn-prediction-streamlit
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python src/data_generation.py
python src/train.py
streamlit run app/streamlit_app.py
```

Then open the local Streamlit URL shown in the terminal. The dashboard includes an overview of portfolio risk, an individual customer explanation view, and downloadable mitigation scorecards.

## Dataset and modeling notes

The dataset is intentionally synthetic and contains customer tenure, charges, support activity, payment behavior, satisfaction, contract type, service configuration, and a binary churn label. It is appropriate for demonstration and portfolio work, not for making decisions about real customers without validation and governance.

The reported ROC-AUC is generated by the training run on a stratified holdout split and is written to `models/metrics.json`. Because the data is generated deterministically, the result is reproducible with the same dependency versions and random seed. The app computes risk probabilities from the saved preprocessing pipeline and model rather than retraining at page load.

## Responsible use

Risk predictions are decision-support signals, not ground truth. Account managers should validate the underlying customer context, avoid discriminatory use, and measure retention outcomes after interventions. Before production use, add temporal validation, calibration, monitoring for drift, privacy controls, and human review.
